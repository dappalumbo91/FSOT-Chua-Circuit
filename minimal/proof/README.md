# Computer-assisted proof (C++20, interval arithmetic)

**System:** the ideal minimal jerk x''' = −A x'' − x' + |x| − 1, with A = 1/φ. A is enclosed rigorously from √5, and this is the LOCK M1 hypothesis value.

The FSOT-derived knob A = γ_rel (LOCK D1) has no bounded attractor: it is unbounded in the ideal model and latches to the rail in the real circuit. A chaos proof at that parameter is therefore impossible, and the proof is done at the M1-locked value.

## Method
- **Section:** Σ = {x = 0}. The return map is P = P₋∘P₊.
- **Flows:** in each half-space the flow is linear, so v(t) = v* + e^{Mt}(v₀ − v*). e^{M[0,h]} (h = 1/32) is enclosed by a 14-term Taylor series with a rigorous remainder.
- **Rounding:** every +, −, × and ÷ is rounded outward by one ulp (iv.hpp). No libm transcendental functions are used.
- **Crossings:** for each step the code proves the sign of x. In the crossing window, x is proven strictly monotone (sign of y) and the crossing is pinned down by sub-interval refinement.
- **Covering relations** (Zgliczyński–Gidea, u = s = 1): an h-set N is a parallelogram c + uU + sS. N ⇒ N under P is verified by two checks over a 1000 × 40 box subdivision:
  - (i) |s(P(N))| < 1;
  - (ii) the two u-edges map to u < −1 and u > +1, one each.

## Verified result (`./proof check hsets.txt`, about 25 s on 8 threads)
- **Na ⇒ Na under P: VERIFIED** (max |s| = 0.48).
- By the covering-relation theorem, P has a fixed point in Na. So there is a **periodic orbit of the flow, proven to exist**, crossing x = 0 at x' ∈ [1.23, 1.40]. It is numerically unstable, with multiplier ≈ −1.616.

## Not reached
A two-symbol topological horseshoe, which would prove chaos with entropy ≥ ln 2 / k, was not reached.
- P has weak expansion (|μ| ≈ 1.6).
- The attractor's section folds near y ≈ 1.66–1.75.
- Covering by P² fails because of interval wrapping at the current box sizes.
- Next steps: h-sets along the folded branch, and Lohner-type QR wrapping control for P².

# Chaos proof at the FSOT knob A = γ_rel = 0.42804344605980688 (horseshoe.cpp)

**System:** the ideal minimal jerk x''' = −A x'' − x' + |x| − 1. At A = γ_rel it has a thin, small-basin attractor (LOCK T2; png/gammarel_section_horseshoe.png). The real-diode circuit does not show it (T2-4 and T2-5 falsified).

## Method (everything implemented here, no external libraries)
- **Section:** Σ = {x = 0, x' > 0}. P is factorised into short linear flights: every half-space flight is cut at each extremum (y = 0). That keeps ‖e^{Mt}‖ small.
- **Crossings:** strict sign checks on a 1/32 grid, then an interval Newton contraction for the crossing time.
- **Flight Jacobian:** J = (I − f e_bᵀ / f_b) e^{Mt*}, restricted to the free coordinates of the two sections.
- **Set propagation:** preconditioned affine form c + G·(du, ds), where G = DP·[U S] is carried column-wise. This avoids the wrapping blow-up of interval products of non-normal Jacobians. Thin centres are propagated by mean-value steps.
- **Covering relations:** Zgliczyński–Gidea, u = s = 1, Theorem-16-type sufficient conditions:
  - (a) the u-edges map to opposite sides, |u_M| > 1;
  - (b) the image avoids {|u_M| ≤ 1, |s_M| = 1};
  - (c) the central line avoids {|u_M| ≤ 1, |s_M| ≥ 1}.
- **h-sets:** N1 and N2 (golden.txt, generated by mk_hsets.py) lie on the left attractor band. u runs along the band and s along the numerically computed stable direction of P⁴. They are subdivided into 300 × 16 boxes.
- **Iterate:** P⁴, which is g² for the two-band return g = P².

## Result: VERIFIED (horseshoe_run.log; about 4 min on 8 threads)
```

N1 =P^4=> N2 : VERIFIED (max|s| on |u|<=1: 0.5524)
N2 =P^4=> N1 : VERIFIED (max|s| on |u|<=1: 0.2862)
```

- N1 and N2 are disjoint: N1 has y ≤ 1.91194 and N2 has y ≥ 1.91208.
- So P⁴ is semi-conjugate on an invariant subset of N1 ∪ N2 to the full shift on 2 symbols. The Poincaré map has **topological entropy ≥ ln2/4 ≈ 0.173**, and the flow has a chaotic invariant set at the exact FSOT knob A = γ_rel (binary64 value 0.42804344605980688).

**Scope:**
- The proof covers the ideal piecewise-linear ODE. It does not cover the 1N4148 circuit, where the γ_rel set is not observed (LOCK T2).
- It proves a chaotic invariant set, not that the observed attractor is chaotic.
- Rigour assumes IEEE-754 correctly rounded +, −, ×, ÷, widened outward by one ulp. No transcendental library calls are used.
- The h-set geometry (mk_hsets.py, section_gammarel.npy) is non-rigorous input. Only the check is rigorous.
