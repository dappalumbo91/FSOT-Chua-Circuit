# LOCK PJ: Path J. FSOT-derived x′ gain and |x| slope for the γ_rel jerk. Candidate set, selection rule and blind predictions, locked BEFORE any simulation of these candidates

## Correction to LOCK T (LOCK T itself is left untouched)
LOCK T's F1 screen claimed that x‴ + γ x″ + B x′ = |x| − 1 depends only on A_eff = γ/√B, "whatever the slope". That is **wrong**.
- Rescale t → t√B. The family becomes x‴ + a x″ + x′ = q|x| − c, with a = γ/√B and q = G/B^{3/2} (G is the |x| slope, here 1). The offset c is removed by scaling the amplitude, but q is not: at x₊ the characteristic polynomial is λ³ + aλ² + λ − q.
- So the family has two essential parameters, (a, q). The F1 analytic "fail" of all 7 B values was unfounded.
- The F1 candidates were never simulated (topo/tj_all.txt contains only S-a … A-c). They are therefore clean for a blind test.

## Selection rule (locked)
1. Run C++ (pathj/pj.cpp: RK4, h = 0.002, transient 500 τ0, T = 3000 τ0, two-trajectory λ1) on all 49 candidates.
2. Draw 64 seeds (mt19937 seed 1), uniform in x ∈ [−2.5, 2.5]/G and x′, x″ ∈ [−1, 1]/G.
3. A seed counts if it stays bounded (|x| < 50/G) and λ1 > 0.005/τ0.
4. Winner = the largest basin fraction. Ties go to fewer non-unity coefficients, then to χ closest to 0.594.
